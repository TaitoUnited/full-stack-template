# React conventions

Read [client overview](../../../docs/client/README.md), [code style](../../../docs/code-style.md), and the relevant client topic documentation.

- Keep route components in `client/src/routes/` and reusable UI in `client/src/components/`.
- Use the generated Panda CSS system and existing UI-kit patterns before introducing one-off styles or primitives.
- Keep rendering, loading, error, and accessibility states explicit; test changed behavior with the client scripts.
